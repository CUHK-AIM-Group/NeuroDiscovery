## 2. 冻结科学定义

| 层 | 用途 | 能否计为严格共享支持 |
|---|---|---|
| 原始观察 | 保存每篇论文的实际测量、结果、条件与锚点 | 不直接计数 |
| 严格命题 | 同一关系、测量含义和必要范围的不同表达 | 审核通过后可复用 claim |
| 范围层级/主题关系 | 连接更窄、更宽、相近但不同的命题 | 不能替代等价合并 |
| 研究问题分组 | 将同一问题的不同结果放在一起浏览 | 不计作同一正向命题的支持 |

只有 `equivalent` 可作为复用同一严格 claim 的候选。`narrower_than`、`broader_than` 保留独立节点与有向边；包含关系本身也须有证据，不能把同属一个疾病家族视为包含。子群中观察到的效应不能直接外推为整个群体的效应。

不同队列/论文不是天然的必要范围差异，也不是独立复现的保证。物种、阶段、对照、测量、干预、时间及调整模型是否影响研究所估计的关系，应结合源文判定；不能将其中任一自由文本字段的字符串差异一律当作硬冲突，也不能一律降成可忽略变体。

方向和不显著结果分别保存。相反方向只有在问题与范围匹配时才可能构成反向证据；不显著不是效应不存在，更不自动是反证。共享问题与共享断言分别计数，不能靠切换定义增加多论文率。

区分 primary_result、synthesis_result、background、hypothesis、method、protocol。背景和综述不能获得独立原始复现信用；同一作品多个版本只计一次，队列重叠为未知时明示未知。

### 本轮修复的真实缺陷（增量，不覆盖旧产物）

1. **一致性地基词缺失（最大项）。** 签名词表只有屈折形，导致 `decrease`/`increase`/`elevated`/`thinner`/`impaired`/`reduction` 等字面签名被判 `not_source_bound`。加基形 + 正则允许常规英语屈折（`_INFLECTION`）。**不改判定语义，只补表达**。
2. **临床术语误判。** `negative symptoms` / `positive symptoms` 是症状名而非方向词，曾被读成签名并"矛盾"。新增 `_CLINICAL_SYMPTOM_TERM` 先行剔除，`signed_word_hits` 统一走它。
3. **`significative`（英式拼写）** 未被显著标志匹配，导致明文显著结果被判 `significance_not_source_bound`。新增 `_SIGNIFICANCE_STEM` 正则。
4. **`sample_number_not_source_bound` 仍有三类缺口**：`n=null`（诚实留空，不是编造数字）、**子句内**分量求和（`40 male and 42 female … (age: 33.3+/-9)` → 82，且括号内年龄不得混入）、单病例措辞（`We report a case of schizophrenia` → 1）。`component_sum_matches` 改为按 `;()` 切子句；`singular_subject_match` 支持 `a/an/one + 描述词 + case/patient/…`。**分量求和与命名不符仍是硬错误**（保留反例测试）。
5. **`p ≤ …` 的 Unicode 运算符**被 ASCII-only 结构校验器判为缺失。`validator_limitations` 现在把 `≤/≥` 计入缺口。
6. **"induce/enhance" 类使役动词不是签名**：`a deficit can be induced` 曾被读成正向而误判 `lower`。移除 `induce/promote`，只保留真正的量级词。

### 本轮修复的真实工程缺陷

7. **DOI 工作键的候选文件名越级。** `DOI:10.64898/2026.05.08.723648` 只替换了 `:`，`/` 使候选写到 `candidates/DOI_10.64898/` 子目录。新增 `safe_stem()` 收敛所有非法字符，修正了运行器与既有落盘文件（已核对路径在 `tmp` 内），并加了回归测试。

### 仍存在的、不是我们规则问题的 HELD（真实模型缺陷，保留）

## 4. 新样本与冻结方式

### 4.1 一个 120 篇实验，不逐轮复制语料

- 从已有 CORPUS 输入索引的 `fold=corpus` 选取 3 个连贯子主题，各 40 篇：MCI/AD 海马结构、TLE 海马与记忆、精神分裂症海马结构。确切入选条件、种子和排序在执行前冻结。
- 排除旧 40/200 篇 pilot、16 篇重抽、历史人工参考及其他已曝光实验论文；按作品身份排除版本重复。曝光记录有缺口的论文不能标为未见。
- 原有 40 篇 heldout 一律不读不改；新验证样本只是 CORPUS 内预留集，不占用这 40 篇。
- 在满足来源可读与主题条件的池内固定抽样，不按旧 claim 或预期会合并来挑论文。某子主题不足 40 篇未见材料则报告不足并调整计划，不暗中复用旧样本。
- 其中先冻结 12 篇作为传输/速度冒烟，仍属于同一 120 篇；若通过，复用其成功结果只处理余下 108 篇。冒烟中发现必须改提示/代码的问题则结束该版本实验，不把修复后的数据混入同版确认结果。

### 4.2 人工对照先于 API 输出

- 预选 24 篇（每主题 8 篇），root 从完整可用摘要独立列出结果单元、必要条件、证据角色和原句锚点，冻结参考后才运行模型。只有摘要就只评价摘要可得信息，不声称完整论文覆盖。
- 从源阅读构建约 60 个命题配对的诊断面板，覆盖严格等价、范围包含、相近非等价、null/不确定案例。不要为了凑正例配额把相关关系标等价；每对两侧均记录实际阅读范围。
- 配对尽量限制同一论文反复出现，并记录论文/队列重用。选中的 24 篇不足以提供面板时，在这 120 篇内补读，记录新增人工时间，不另建来源库。
- 若正例不足，报告“无法精确估计召回”，不能把全部拒绝当成功。合成同义改写可做单元测试，不能充当跨论文科学正例。
- 参考冻结包含时间、来源哈希、判定理由和规则版本；模型不可访问参考答案。root 非人类专家，也不是独立验证者，结果称为“root 源阅读参考一致性”。
- 查看模型结果后发现参考错漏，只能另存修订及解释，同时保留原评分；该样本随后转为开发数据，不再宣称未见验证。

## 5. 分离四种误差，不只看多论文率

| 实验 | 输入与对照 | 要回答的问题 |
|---|---|---|
| A：抽取 | 24 篇完整摘要，人工结果单元 vs API 候选 | 是否漏掉结果、编造符号、丢范围或误标证据角色 |
| B：召回 | 源阅读参考中的正例、真实 API 观察、已冻结检索配置 | 对端点表达不同的真实同命题，能否找到候选 |
| C：裁决 | 约 60 对源绑定命题，输入不附参考标签 | 是否正确区分等价、包含、相关与不足 |
| D：端到端 | 同一 120 篇所有抽取→召回→裁决→隔离暂存结果 | 整条管线实际得到多少可信的跨论文共享命题 |

B 同时报告“端到端正例可达率”和“双方均正确抽出时的条件召回率”，避免抽取遗漏被当成召回成功。C 的人工整理输入只用于隔离裁决能力，不能替代 D 的真实 API 输入评估。

如果比较词法与语义召回，只在相同抽取观察上比较预先冻结的两种配置；固定 top-k、索引及嵌入版本，再送同一裁决器。约 60 对面板评估配对判断，不代表主题中的自然发生率。不得在该面板上反复调阈值再报告未见成绩。

人工比较记录实际阅读/标注时间，API 记录请求时长和总墙钟。不能拿 JSON 生成的毫秒数冒充人工阅读速度。各 provider 单独统计，失败和 HOLD 也进入总耗时与吞吐。

## 6. 指标与拟定判定条件

### 6.1 核心指标

- 抽取：有源支持的结果单元召回、无源断言比例、关键范围/数值/角色错误、程序误拦比例；程序通过率单列。
- 召回：在人工已确认正例中的检索命中率，及抽取缺失、未召回、门拦截、模型拒绝的逐阶段损失。
- 裁决：严格等价精确率与召回率、范围关系识别、HOLD 比例；按真实模型判定与硬规则判定分别报告。
- 效益：每个主题内，获至少 2 个不同作品 primary_result 正向支持的严格命题数 / 该主题内获至少 1 个此类支持的严格命题数。固定同一论文集合对比浅层 exact-key 基线和语义方案；不能删掉单论文命题或改变主题范围来提高比例。
- 同时报告分子/分母绝对数、成功/失败论文数、失去的结果单元、主题组/范围边数量。多论文率只对保留命题计算可能有选择偏差，必须同时报告 120 篇全体输入覆盖率；已审核与未审核计数分开。
- 作品数与已确认独立队列数分别报告。背景、综述、不显著、反向证据不计入独立正向复现；保留为其他角色的证据。
- 速度：首 12 篇和全部 120 篇的 p50/p95 延迟、成功/尝试吞吐、裁决延迟、人工修正时间、失败重试、token/已知费用及新增磁盘量。

### 6.2 判定不追求预设多论文百分比

建议的本轮扩大试验条件：

1. 来源/固定边界/heldout 写保护、防重发及额度回退技术测试全部通过。
2. 人工核对中无关键条件被抹除的错误合并；抽取结果单元覆盖率目标至少 90%，同时报告实际分母、错误与不确定性。零抽取/零合并不能通过效益验收。
3. 真实严格等价正例上的召回目标至少 80%；不足以形成可靠分母时结论是 INCONCLUSIVE，不是降标准或宣称失败证明无可合并内容。
4. 新增严格多论文支持必须经过源审核，且未以牺牲抽取覆盖来换取比例。增加多少如实报告，不承诺命题总数或多论文率必定上升。

这些是进入更大确认实验的建议门槛，不是无人监管/全库发布标准。小样本零误并不能证明 98% 精确率：例如在独立、代表性的合并样本中，约 149 次连续正确才使单侧 95% 二项下界达到约 98%；本轮主题富集且论文对相关，不能直接套用这一保证。报告相应区间及按作品聚类的不确定性，不能将 2/2 写成已证明安全。

- 401、解析失败、输出不科学不触发 provider 回退。未知请求状态 HOLD；失败可诊断，但不盲目换槽或换目录重发。
- 任一严重误并、来源错配、防重发失效或非额度回退，停止新增请求并保留在途结果；输出失败报告。修复后另建版本，旧结果不抹除。
- 首轮完成后只给出“继续扩大 / 修复后新验证 / 证据不足”结论。本计划不包含自动循环直到通过，也不包含生产发布。

## 8. 文件与空间生命周期

- 一个小型新实验目录，记录配置、样本 ID/快照引用、代码与提示哈希、人工参考、逐次账本、原始响应、错误及摘要指标。不复制 CORPUS、固定图、旧运行目录或完整索引。
- 只保存选中论文所需输入。可恢复的运行状态与结果按请求 ID 写入，避免每次重试复制整套摘要。
- 同一响应仅保留一份权威原始对象；派生候选与阅读显示引用它，避免重复保留大段原文、pretty-print 全量报告及每轮数据库副本。
- 在首次运行前建立清理清单：每个生成文件记录用途、大小、是否可再生成、依赖、删除条件。原始响应、来源绑定、参考及审计账本在验收前保留。
- 临时显示、短期索引和解析缓存只有在不承载唯一证据、验收完成且无运行依赖时才可清理；先核对绝对路径与 reparse point。未经确认不清理旧审计材料或其他项目文件。
- 输出逻辑新增字节与可取得的实际占用；不把逻辑字节数直接当作真实释放空间。本轮规划不删除文件。

## 9. 本轮交付与执行顺序

本轮交付仅为此计划与入口纠偏提示。批准执行后依次：离线修复/更正旧参考 → 冻结新样本与源阅读参考 → 12 篇冒烟 → 余下 108 篇及有界裁决 → 根源核查与完整报告 → 按清单处理可删除派生物。若任一阶段不满足条件，保留证据并报告，不暗中放宽规则。
