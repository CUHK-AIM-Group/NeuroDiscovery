关闭旧客户端后安装或打开新版，在顶部 **NeuroDiscovery → 专家研究 / Expert Study** 进入完整成果评审。问卷在客户端内打开，不依赖原来 8769 端口的独立预览服务。

问卷顶部始终提供中文 / English 切换。案例材料、题目、选项及汇总同步切换；原始论文英文、数值和用户备注保持原文。切换不重置答案或当前案例。启动仍进入常规工作区，不自动弹出问卷邀请。旧“研究结果”入口与原假设排序问卷记录保留。
