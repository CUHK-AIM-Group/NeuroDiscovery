## 1. 本次要回答的问题

旧问卷主要让专家比较假设的合理性或预测外部验证结果。它不能单独回答“系统是否产生了有意义的新科研成果”。新入口让专家审阅一条完整的研究链：

**既往证据 → 明确假设 → 测量和检验设计 → 内部实验 → 外部组成/敏感性 → 后轮反馈利用 → 结果的科学含义。**

核心不是与博士研究者比速度、猜实验结果，或让专家给系统性能打一个总分。核心是将三种不同判断分别记录：

1. **新颖性**：相对于已有研究，这个具体命题有多大实质增量？
2. **实验支持**：实际结果在其声明范围内提供了多充分的支持？
3. **科学意义**：结果增加了多少有用的科学信息，包括复核、扩展、不支持结果或新关联？

另用单选题记录产出类型，避免把所有有价值结果都命名为“首次发现”。专家意见不能代替统计验证、独立重复、文献首次性核查或因果证据。

## 4. 每位专家的流程

### 入口

记录匿名代号、主要专业、研究年限、旧版问卷参与情况、既往结果/实验接触情况、用途（pilot/test）及试用保存说明确认。不收集姓名、邮箱、患者资料；不做第三方访问统计。

专业选项包括神经影像、临床神经科学/精神病学、计算神经科学、AI4S/机器学习、统计/方法、影像遗传及其他交叉学科。“博士”不是每个维度都能判断的保证，所以始终允许“超出专业范围”。

### 阶段 A：先看三份假设和设计，再看任何候选结果

显示精确假设、atlas/ROI/网络/诊断定义、真实提议理由、既往文献与不足、内部/外部方法和先前数据接触情况。不显示当前候选结果和父反馈的数值。

每份 3 个必答单选：

| 编号 | 判断内容 | 选项结构 |
|---|---|---|
| A1 grounding | 既往证据是否为提出该假设提供合理依据 | 不相关/误读；部分依据；有依据且限制清楚；无法判断 |
| A2 novelty | 具体命题的实质新颖性 | 1–5 级锚定评分；材料不足；超出专业 |
| A3 design | 数据与分析能否检验核心假设 | 不能；只能检验部分/弱命题；能检验限定范围；无法判断 |

**新颖性锚点：**1 相同问题已被直接报道；2 主要是标签/相邻分区/技术变化；3 新诊断组合、人群或测量定义上的实质扩展；4 重要且既有证据未直接覆盖的关系/边界；5 明显不同、可能改变既有理解的命题。未检索到不等于全球首次；给定材料不足时不强迫评分。

可加简短理由或补充文献。全部三份的 A 阶段完成后，明确确认并锁定，再统一开放 B 阶段。

这只能减少本次界面引起的结果曝光，不会消除研究者既往记忆。既往看过结果的参与者不得被描述为结果盲评者。原模型生成上下文包含更早 TCP 反馈；A 阶段为避免相关结果曝光而暂隐其数值，不宣称完整再现生成上下文。

### 阶段 B：完整研究成果

显示固定内部结果、全部外部组成/敏感性、真实父反馈到后轮提议、讨论后的实际决策摘要及方法限制。原始六次模型角色讨论及来源映射保存在主办方包中，评审界面是汇总展示，不是完整日志重放。

每份 9 个必答单选：

| 编号 | 判断内容 | 作用 |
|---|---|---|
| B1 validity | 是否形成可解释的有效分析 | 将执行/方法失败与科学不支持分开 |
| B2 outcome | 核心假设的经验结果 | 明确反向；不确定/部分支持；探索性支持；无法判断 |
| B3 evidence | 对核心关联的支持充分性 | 1–5 级锚定评分 |
| B4 value | 有意义的科学信息增量 | 1–5 级锚定评分；允许负结果有价值 |
| B5 contribution_type | 成果属于哪一类 | 已知复核、实质扩展、有证据的新关联、待验证候选、有价值的不支持/反向、不可解释、无法判断 |
| B6 conclusion_fit | 整理者摘要是否与证据一致 | 摘要超出证据程度；不是模型写结论能力 |
| B7 traceability | 主要结论能否追溯到所示记录 | 材料可追溯性，不等同实际重新运行 |
| B8 coverage | 外部结果是否支持全部具名诊断组成 | 不把精神病组成结果当作 ADHD/双相复制 |
| B9 feedback | 后轮提议是否合理利用真实反馈 | 闭环过程的可解释性，不证明反馈的因果增益 |

证据评分从“很弱/相互冲突”，经“有实质支持但限制明显”，到“限定范围内充分且主要替代解释得到妥善处理”。科学意义从“无可信信息增量”，经“有价值的复核、扩展或适用边界”，到“对具体问题构成实质推进”。三种分数不相加，不定义任意权重的“发现总分”。

共 **3 份 × (3 + 9) = 36 个必答项**，另有可选问题标签和短备注。35–50 分钟只是尚待人类试评验证的负担估计，不能作为已测结果报告。

## 5. 必须保留的材料解释边界

- 本批测量是固定 Pearson r 边的算术均值；标准化效应为 β / 残差 RMS，**不是 Cohen d**。
- bootstrap 范围是描述性百分位，不是校准置信区间；未提供本家族确证 P/q 推断。方向频率不是科学命题为真的概率。
- TCP 为同一来源样本，多 seed 不增加独立被试；外部两阶段也共用参与者。
- UCLA 原精神病比较是 SCHZ；COBRE 含 SZ/SZA 并有 SZ-only 敏感性；HCP-EP 非情感性精神病为组成推广，情感性背景不是双相复现。显示名按实际比较限定，而不简单沿用生成时的宽泛 domain。
- 外部队列不是从未接触的全新 holdout；跨队列身份零重叠也尚未穷尽认证。
- 来源文献尚有全文核查和最接近既往结果检索缺口。旧候选清单中不存在，不等于从未被科学界发现。
- 本批**没有外部分析后的模型自然语言总结**。展示的解释是整理者摘要，必须如此署名，不可据其评分宣称系统独立形成了结论。
- 三份研究材料均来自一个系统；即使隐藏方法/提供方，也不是完善的双盲方法比较，专家可能从内容推知来源。
- 本版没有完整流程的同条件对照研究报告，因此不估计“比博士/其他系统发现能力高多少”。原排名基准不能替代此处完整成果对照。

## 7. 试评结果如何整理

当前不预填任何“人类评价结果”。第一轮先检查题意、负担、材料缺失和不适用率；结合评审备注优化文本，再冻结正式版。

预定报告单位是 **专家 × 完整假设成果包**，不是 bootstrap 重复、seed、组成表格行或同一指标的多个诊断变体。

- test 与 pilot 严格分开；本次自动化和浏览器测试全部排除。
- 按 pack/protocol 版本分别报告，不混合不同证据版本。
- 先逐份、逐维度报告回答分布、可判断人数、无法判断原因和未完成情况；不删除低分或异议。
- 三个 1–5 级维度分别呈现等级分布和中位数/四分位数；类别题报告原始人数与明确分母。
- 主专业、既往问卷、既往结果曝光需单独记录和说明；不能把领域外“无法判断”作为系统失败或专家能力低。
- 若正式版要报告“获专家认可的新关联比例”，应事先锁定判断规则、分母、无法判断处理和抽样方法；不能在看分数后组合新颖性/支持度阈值。
- 数十位专家重复审阅三份示例，增加的是这些示例上的意见信息，不会把三份例子变成数十个独立发现。正式总体推断还需要扩大成果样本并考虑专家与成果的重复/相关结构。

本版不预先声称统计功效，不做真实参与者评分的自动汇总或显著性检验。正式分析模型和主要终点在最终材料/评审分配明确后再锁定。
