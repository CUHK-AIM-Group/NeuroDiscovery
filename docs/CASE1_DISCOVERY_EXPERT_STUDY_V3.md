# Case Study 1 专家评估 · v3 单轮逐例评审

更新日期：2026-09-15。状态：本机试用；不是正式招募或已验证量表。

## 本次决定

按用户反馈取消问卷 A/B 两轮。每次展示一个完整案例的假设、提出依据、方法、内外部分析、真实反馈及解释边界，在同一页完成六项评分后继续下一例。保持十例、每例六题、共六十题。

旧设计为了使假设与设计初评先于结果展示，但先评全部十例再回到第一例带来延迟回忆负担。本版以完整成果评价为目标，取消该展示门槛。不能再声称获得了结果盲评、实验前的新颖性判断或前后评分变化。

## 页面与操作

1. 入口只收匿名代号、相关研究年限和填写确认。
2. 每例的假设、依据、共同方法、引用与核查缺口、完整内外部结果、实际父反馈及模型讨论同页可见。不按支持强弱删减表格。
3. 评分区再次展示当前假设及回看链接，不要求记住上一轮内容。
4. 六项能力：证据整合、新假设提出、实验设计、实验验证、科学信息增量、反馈驱动迭代。
5. 每项保留原有文字锚点和 1–5 分映射；材料不足或超出专业范围仍记 null。
6. 点击“保存并评下一份”切换；导航可回看。提交前可修改，最终提交检查全部六十项并锁定。没有中途初评分锁，也不再有解锁实验结果操作。
7. 暂停/刷新恢复后定位首个未答完案例。全部完成后可查看六项均分和综合均分，并导出记录。
8. 本次没有实施限时；此前每例时长建议仍待真实试填验证。

## 评分与解释边界

数值计算保持原算法：每例六项均有数值才计算该例综合均分；个人汇总报告覆盖数；研究层面按案例等权汇总，同时报告各能力分布和未评分原因。不将 null 编成零或中点，不把测试记录混入专家记录。

变化是评分的信息条件，而非把同一个分数换名字。全部评分现在都是在完整成果可见条件下作出的评价；新颖性评价仍只依据命题与已有知识的差异，实验验证题仍评价验证质量，不以是否得到阳性结果评分。以上提示有助于明确任务，但不保证消除结果偏倚。

本问卷没有无反馈对照、完整方法间对照或随机化展示条件对照；不能从均分推断系统相对人类/其他系统的因果优势，也不能把高分当成首次发现认证、实验复现或全体候选的自然成功率。十例的原选材范围和探索性统计边界保留。
