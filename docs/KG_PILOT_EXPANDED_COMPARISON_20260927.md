## 结论

**可以继续让 API 做候选抽取，但当前不能放手让它自动合并并发布 KG。**
本次复用重启前已完成的 200 篇抽取及 303 对裁决，没有重复发送请求。新增工作是 root 源摘要阅读、对照、只读账本核验和报告；没有修改固定神经科学层、生产图、原始语料、40 篇 heldout 或 E:。

问题不能简单归结为模型能力不足：现有裁决提示明确说不同 populations/species 不构成差异，实际鼓励跨病种错误合并；信息传递和去重代码还会丢掉必要范围。必须先修实验规则，才能公平判断模型能否独立承担任务。

## 纯源手工抽取对照

用 seed 927 从新增 160 篇随机选 6 篇，先形成源摘要结果参考，再查看对应 API 抽取。参考文件记录阅读范围、原文引用和 source_sha256。root 有先前会话摘要，并非独立或完全盲法验证；只读摘要，不冒充读过全文。

6 篇为 PMID 38553838、21945401、15012840、35449033、28138428，以及 DOI 10.1109/isbi53787.2023.10230714。

- root 记录 28 个源结果单元；API 给出 45 条观察，28 个单元均有对应内容。复合结果可能拆成几条观察，不能用 45 对 28 判断谁创造更多有效命题，也不能称科学准确率 100%。
- 正面例子：区分 super-ager 研究背景与本研究结果；保留调整条件；NUAK1 的 possible 状态标为 partial；MCAO 的 MMSE 关联没有擅自确定正负。
- 确认错误：PMID 28138428 第 8 号观察，原文只说 correlated，结构字段却标为 positive，并标 reported_significant；它自己的说明又承认摘要未给方向。这类内部不一致未被校验器截住。
- 空结果语义：多处把“不显著”编码为 negated/opposes。没有显著证据不等于证明无效应，也不能脱离相同人群/对照成为反证。
- 信息传递问题：PMID 35449033 的 API 实际在 limitations/scope_reason 保留了 Tau 关联未通过 FDR；但裁决包丢掉这些字段。不能误说模型完全漏掉 FDR，真正问题包含下游丢失限制条件。

逐结果映射：`tmp/kg_pilot_20260927_v2/ROOT_EXTRACTION_COMPARISON.json`。

### 随机 24 对

在看对应模型答案前，root 对 seed 927 抽出的 24 对给出参考决策；读取全部候选语句/引句，必要时补读完整摘要，具体范围记录在 `ROOT_PAIR_REFERENCE.json`。

- 六分类完全一致：12/24；是否允许直接合并一致：21/24。
- 其余 3 对是 API 判 equivalent，而 root 判 1 对不同疾病范围、2 对证据不足待核。
- P101 把精神分裂症和临床前痴呆的海马体积下降合成相同命题；模型理由直接引用错误提示中的“不同人群不构成区别”。
- 24 对中没有 root 确认可合并的正例，因此不能估计漏并率；21/24 也不能被描述为全库准确率。

### 定向检查全部 25 个 equivalent

全部 25 个自动 equivalent 中：**20 个拒绝直接等价合并，5 个 HOLD，0 个直接放行**。
这是合并安全检查，不是随机总体精度估计；HOLD 不等于已证明模型错误。

主要拒绝原因是抹去疾病/人群、年龄/阶段或对照范围，例如 PTSD 与血管病、青少年双相与 aMCI、精神分裂症与精神病性抑郁。它们可以属于同一主题家族，但不是同一个完整限定的科学命题。

P216 两篇均为综述/汇总，还需区分成年/儿童、创伤暴露对照和底层研究重叠。两篇文献不自动等于两次独立实验。

## 不能证明多论文率上升

没有把这些裁决写入生产图，也没有验收新的多论文命题。应报告多论文率尚未验证，不用自动合并后的表面比例宣布成功，也不声称语料没有真实可共享命题。

原 RECALL 文件来自旧加载/去重实现，记载 1,106 条观察、删除 106 条“重复”；按有效 candidate_path 重建是 1,240 条观察。口径不一致。303 对的两侧 statement/index 均与对应保留候选相符，但不能据此认可旧去重或召回覆盖率。

必须纠正的旧表述：

- “论文数 × 每篇条数”计算观察条数，不是去重后共享命题数。
- 字符串阈值试验的 2–6% 不是语义可合并上界。
- 以前跨病种 root 合并、1.33% 多论文率及“3 个真实多论文命题”不能作为科学验收依据；root 也必须纠错。
- 目标是正确共享、可追溯证据和保留差异，不是追求更多节点。

## 放手前必须修复

本轮不修改已经使用过的提示/裁决历史，也不悄悄重跑 200 篇。现有 `paper_pilot_adjudicate.py` 的自动合并路径不合格，不应继续用于发布或计科学信用。下一轮应新版本实现：

1. 只读有效候选；方向敏感关系不得无条件交换主宾；去重包含 qualifiers。
2. 携带源摘要、role、result、limitations、notice 和 source hash；区分效应方向、统计显著性和证据立场。
3. 不同必要疾病/物种/阶段不能直接等价，但也不能仅因 cohort ID 不同就拒绝真正跨队列复现；共享命题与具体研究证据分层。
4. 修复逐尝试日志、未知结果 HOLD 和 quota-only 回退。
5. 新验证集同时包含真实等价正例、困难负例、待定例；旧 24/25 对仅作开发回归，不再称未见验证。分别量化误并、漏并、源保真及人工完整耗时，再评估能否只抽查。
