## 3. 图谱相似度设计

### 3.1 结构化当前假设

仅从实验前假设及定义提取检索条件，不用当前实验显著性、方向是否成立或专家评分反向选文献：

- 实体：基因/等位基因、脑区、图谱和 ROI、网络、疾病及人群。
- 关系与测量：基线体积或萎缩速率、功能连接、剂量或携带状态、疾病进展；体积/皮层厚度不混同。
- 设计：横断面/纵向、随访窗、队列、物种、对照和归一化方式。
- 方向：用于后续支持/反对分类，不作为只召回同向结果的过滤条件。

通过现有 `REFERENCE_CATALOG.sqlite` 的 `entities` 查规范名和别名。已确认其中存在 APOE、海马、内嗅皮层、颞中回和感觉运动网络实体；同名存在多个 ID，必须按数据来源、概念类型和既有映射消歧，不能直接合并。Schaefer ROI 必须绑定对应 atlas/version，不能假定等同解剖分区。

### 3.2 三路召回，独立保留来路

1. **实体路径召回**：假设实体 → 既有规范映射/允许的结构邻接 → 文献来源绑定。优先精确端点，受限扩展 1–2 跳；不把任意短路径当作语义相关。
2. **已有引用邻域召回**：由原始引用的可靠书目信息和实体集合找共享端点/测量/人群的文献；不把历史 claim 的结论当作答案。
3. **标题/摘要召回**：复用 retrieval v3 的 FTS5，以规范实体名、审核过的同义词和关系词扩大覆盖，补足论文层尚未重建的空缺。

图谱数据复用已完成的固定层目录与分区，不重新读取 6.76 GB 原图，不重新摄入固定数据，不复活已清理的历史索引。现有固定目录只提供实体和受保护边，**不等于完整的新论文语义网络**；书目/摘要从保留的 CORPUS 和 retrieval v3 获得，论文实体匹配必须另留来源锚点。旧 claim 不能成为抽取答案或默认科学信用。

图邻接缺少端点索引时，对现有小目录作一次有界读取后构造内存邻接，或在本任务专属 sidecar 内建最小索引；不得向固定数据库增加索引。源路径沿用当前有效路径；迁移状态未验收前，不自行切换 E 盘或修改重建配置。

### 3.3 可解释排序，不伪装成支持概率

第一版不需要新增模型或 embedding。每篇候选输出可追踪的分项：

- **实体相似度**：按脑区/基因/疾病等类型分组的 IDF 加权 Jaccard；泛化实体降权。
- **结构相似度**：只计算允许路径类型的匹配、距离衰减和枢纽度惩罚，并输出实际路径与来源；精确实体匹配优于仅上位概念匹配。
- **范围相似度**：人群、测量、设计和时间尺度的匹配；区分不匹配与未知，不把缺失当匹配。
- **文本相关度**：复用 BM25 的候选内排序，不把负 BM25 值直接混入百分比分数。

先分“精确主题 / 邻近机制 / 方法背景”层级，再对可用的图排序、范围排序、文本排序进行固定参数 RRF 融合，例如 `Σ 1/(60 + rank_channel)`。缺失通道不补虚构分数，单独标出图映射覆盖率和降级模式；同分以稳定 work ID 排序。权重、路径白名单和阈值在开发卡上审计后冻结，再验证未参与调参的卡片，不能按期望文献数量倒调阈值。

按 PMID/DOI/PMCID 及已有版本关系合并 work；身份冲突先隔离，不凭相似标题强行合并。减少同一队列/同一方法重复占位，同时保留直接反证、零结果和综述。不同论文不自动视为独立队列。

- 处理通知、更正、撤稿和版本；未解决的通知不进入正常审核通过列表。上表诊断命中本身不自动获得审核信用；本次新增论文另有源摘要审核记录。

- 每篇展示完整标题、年份、链接、研究做了什么、为何相关、主要差异、证据角色；相似度解释展示匹配实体/路径，不写“支持率95%”之类未经校准的结论。

## 5. 评估协议与发布边界

补充文献会改变专家对新颖性和证据整合的判断，因此不能在已启动会话中动态更换材料。

- 原 v14、原引用/注释绑定、已保存回答和计时保持不动。新材料使用新 `pack_id`、哈希和协议修订；作者版与桌面参与者投影一起生成。
- 本次在新 pack 的 `organizer.related_literature` 保存内部来源审计，新版引用说明侧表绑定完整五篇集合；历史侧表不变。通用检索未来才需要实体路径、分项排序等额外检索清单，不虚构本次未计算的图分数。
- 发布前冻结完整文献集、顺序和阅读负担规则；相同卡片的所有新会话看到完全一致的版本，不实时随机检索。
- 明确原评估是否测量“系统当时实际整合的证据”还是“发现相对已有工作的价值”。前者不能因事后补充获得额外系统信用；后者可以使用补充背景，但须单独修订协议。新旧协议结果不得无标记合并。
- 按实际实验/评估截止日过滤可用于新颖性判断的文献；截止日后的论文单列后续相关工作，不能倒推实验时已知。日期不明则标未知并隔离相关结论。
- 导出记录 `related_literature_revision`、材料哈希和协议修订；历史会话从原 snapshot 恢复。安装包离线展示冻结 sidecar，不要求评审者连接完整本地图谱。

- 检索：同义词、同名异义、多 atlas、0/1/多命中、输入顺序变化和稳定排序；图缺失时显式文本降级。

- 身份与科学：同论文多来源/预印本去重、同队列标注、通知隔离、每个展示结论都有原文锚点。数量不能代替相关性或支持审核。

- 对比审核：使用冻结的同一候选池比较文本单路与图增强排序，报告逐卡前10相关率、端点错误率、不同work/队列覆盖和未审核数；参考标签由源文献审核产生。未完成这一步前，不宣称图增强已经优于 BM25。
