# T359_biorxiv_rss_digest: bioRxiv RSS Weekly Digest
## Task Description

Build a weekly digest of new bioRxiv neuroscience preprints matching a keyword set: fetch RSS/collection feeds, filter, rank by relevance, format as Markdown.

## Input Requirement


- No interactive input.


## Constraints

- Keyword set in a config file.

- Relevance ranking rule documented.

- Save all generated artifacts to:
  - benchmark_results/T359_biorxiv_rss_digest/


## Expected Output

Expected output artifact(s):

- `digest_YYYYWW.md`

- `matched_papers.json`


Recommended metadata file:

- result_YYYYMMDD_HHMMSS.json
