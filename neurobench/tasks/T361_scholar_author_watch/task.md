# T361_scholar_author_watch: Author Publication Watch
## Task Description

Watch a list of key authors (OpenAlex IDs) for new publications and produce a digest of their latest papers with abstracts.

## Input Requirement


- No interactive input.


## Constraints

- Author list file as input.

- Deduplicate against previous digest.

- Save all generated artifacts to:
  - benchmark_results/T361_scholar_author_watch/


## Expected Output

Expected output artifact(s):

- `author_digest.md`

- `author_state.json`


Recommended metadata file:

- result_YYYYMMDD_HHMMSS.json
