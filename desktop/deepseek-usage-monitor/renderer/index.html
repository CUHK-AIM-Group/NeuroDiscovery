账号

支持多个 DeepSeek 账号，各自保存独立的 API Key / Session Token 与历史记录。 凭证仅保存在本机（userData/config.json，ACL 锁定为仅当前用户）， 只会发送到 platform.deepseek.com 与 api.deepseek.com。

添加账号

Session Token 获取：浏览器登录 platform.deepseek.com → F12 → Network → 任意请求的 Authorization: Bearer xxx 中 xxx。用于查询消耗明细（按天/按模型/缓存命中）。 等同控制台登录凭证，请勿外泄。

刷新与告警

历史数据（余额/消耗快照）按账号保存在本机 userData/history-<账号id>.jsonl，每次刷新自动追加一条，用于绘制趋势曲线。
